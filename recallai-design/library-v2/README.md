# RecallAI design system v2

Figma documentation: https://www.figma.com/design/jtdPE6oTE3hNoAOn3FTbOS/Untitled?node-id=37-594

The Components · RecallAI page contains all twelve requested documentation groups. Main reusable components are organized separately from the review frame. The documentation uses native-size instances, three balanced columns, Auto Layout, 32 px section gaps and 24 px specimen gaps.

The old showcase was removed. Its source components were moved to Archive · RecallAI v1 to retain existing application-screen instance links. Application screens were preserved.

The v2 library includes versioned primitive and semantic variable collections, semantic aliases, explicit scopes and CSS variable code syntax; seven Inter text styles; two elevation styles; 36/44/52 px buttons; form, authentication, role, quiz, flashcard and navigation state sets; learning/teacher cards; and feedback/system states.

The JavaScript files record the construction phases for review. They require Figma Plugin API context and should not be run indiscriminately against an existing completed library. Figma IDs and validation evidence are in design-state.json.

Completed validation: all twelve sections visually reviewed; 237 main component definitions and 23 variant sets; no detected text overflow; Inter typography; button heights 36/44/52 px; mascot size variants 48/96/180 px; application frames preserved.

The final 3D robot is saved as `recallai-robot-3d-final.png` and embedded in the library through one reusable master. Figma AI credits were used. The earlier `recallai-robot-3d.png` is an intermediate render and is not used by the finished library.
