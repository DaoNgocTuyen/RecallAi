# Frontend RecallAI

Ứng dụng chính sử dụng **Flutter / Dart** và nằm trong [`flutter_app`](flutter_app).

```powershell
cd frontend/flutter_app
flutter pub get
flutter run -d chrome
```

Nếu đang đứng trong thư mục `frontend`, chỉ cần `cd flutter_app` trước khi chạy Flutter.

- `flutter_app/`: giao diện sinh viên và giáo viên, responsive cho desktop và điện thoại; dùng ảnh, biểu tượng và font Inter từ thiết kế.
- `react_reference/`: bản React/Vite cùng tài nguyên và bản xuất Figma đã có trước đó, được giữ riêng để tham khảo.

Chỉ có frontend và dữ liệu mẫu cục bộ. Chưa kết nối API, AI, xác thực thật hoặc xử lý PDF.
